02 / BRING YOUR MODEL

Choose a provider.

Add a repository secret named COMPASS_BOB_API_KEY.

Use a Bob Inference-scope API key. Bob Shell 2.0.5 is required; the workflow installs and verifies it.

Store your model key in GitHub Secrets; the runner uses it to call your provider. GitHub supplies the default GitHub token. Never enter API keys on this website.

03 / ENABLE COMPASS

Make the next PR automatic.

Save the workflow as .github/workflows/compass-auto.yml in your repository’s default branch. Add these Actions variables, enabling Compass last:

COMPASS_ACTION_SHA
Reviewed implementation: ceb80097ef1595b7496cfab95aacd77cf2f97145. Pin this full commit SHA rather than a moving branch.
COMPASS_PROVIDER
bob
COMPASS_ACCEPT_BOB_LICENSE
true — after accepting IBM’s license
COMPASS_ENABLED
true — authorizes automatic paid analysis and PR comments. Set false to pause.

Requested limit: 0.5 Bobcoins and four turns. Repair is disabled. Verify actual usage with IBM.

For private repositories, also set COMPASS_ALLOW_PRIVATE=true to authorize sending selected code context to your model provider. Each eligible PR event can cost credits; there is no daily budget cap in this workflow.

Download workflow ↓

Opens, updates, reopens, and ready-for-review events trigger eligible PRs. Draft, fork, and bot-authored PRs are skipped, as are rerun attempts. Use this with trusted repository contributors who can access Actions secrets.

Which bot will comment? The default workflow posts as github-actions[bot]. Our demo repository uses the Compass by North GitHub App and North’s avatar. External users may configure their own App; our private key is never shared. Installing the public Compass App alone does not activate reviews. Hosted sign-in and model onboarding are not live yet. External-user setup ↗

What you’ll see: Gathering context → Analyzing context → Posting comment → Brief posted. Compass provides context; it does not approve or merge the PR. Live Bob execution and bot publication are verified in our demo repository. An analysis failure produces an unavailable brief and a failed check.
